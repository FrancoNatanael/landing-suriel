# SURIEL Landing

Landing de SURIEL Ingeniería y Servicios. Next.js 16 (App Router), React 19, Tailwind CSS v4, TypeScript.

## Desarrollo

```bash
npm install
npm run dev
npm run lint
npm run build
```

## Estructura

- `app/`: layout, página y `globals.css` (tokens en `@theme`).
- `components/ui`, `layout`, `blocks`, `sections`: primitivas, estructura, piezas de negocio y secciones.
- `content/`: todo el texto y los datos de la landing.
- `lib/`: utilidades.
- `public/images`, `public/logos`: assets.

Las reglas y fases del proyecto están en el spec técnico (`SURIEL_Spec_Tecnico_Next.md`).
